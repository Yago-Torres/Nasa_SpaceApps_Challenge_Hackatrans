## Objetivo
Colaboración internacional real y prueba de intercambio. Contribución a **Global Connection**. Fase **F4**, prioridad **P1**.

**Responsable sugerido:** B (A = Codex/ChatGPT; B = Claude ciencia/agronomía; C = Claude interfaz/producto). La asignación es flexible: cualquier integrante o agente puede avanzar esta tarea.

**Dependencias técnicas orientativas:** ABB-25, ABB-31. No son bloqueos de aprobación: se puede trabajar en componentes independientes, tests, prototipos o contratos provisionales mientras se integran dependencias.

## Pasos de implementación
- [ ] Contactar a una segunda comunidad/persona voluntaria de otro contexto regional.
- [ ] Solicitar revisión de un caso anonimizado o una hipótesis usando el flujo de colaboración.
- [ ] Guardar evidencia de la interacción con consentimiento, fecha y contribución real.
- [ ] Recoger barreras idiomáticas y mejorar EN/ES si procede.

## Criterios de aceptación
- [ ] Existe al menos una aportación humana real y verificable al caso.

- [ ] Se respeta privacidad y se puede retirar consentimiento.
