# Documentation-specific agent instructions

Inherit root `AGENTS.md`.
- Documentation changes must preserve product/scope consistency and distinguish `IMPLEMENTED`, `IN PROGRESS`, `SPECIFIED NOT BUILT` and `PROPOSED`.
- `docs/operations/CURRENT_STATE.md` is a reviewed status ledger, not a list of aspirations.
- Changes to architectural decisions go into an ADR with alternatives, consequences and review notes.
- Keep documentation focused on the current roadmap requirements and verified implementation.
