# Documentation-specific agent instructions

Inherit root `AGENTS.md`.
- Documentation changes must preserve product/scope consistency and distinguish `IMPLEMENTED`, `IN PROGRESS`, `APPROVED NOT BUILT` and `PROPOSED`.
- `docs/operations/CURRENT_STATE.md` is a reviewed status ledger, not a list of aspirations.
- Changes to architectural decisions go into an ADR with human team approval.
- Keep documentation focused on the currently approved product requirements and verified implementation.
