# 1.0 release checklist — do not claim completion without evidence

- [ ] All F-01 to F-12 acceptance requirements satisfied and marked COMPLETE in CURRENT_STATE.
- [ ] User can investigate a real local case end to end and verify observations; no sample data presented as live.
- [ ] Three meaningful rotation scenarios, including current, compared under same stated climate context and constraints.
- [ ] DOI/metadata verified, citations accurate, findings human-reviewed where required.
- [ ] Scientific caveats, alternate hypotheses and missing local data prominent.
- [ ] NASA data source, spatial/temporal resolution, cache/source identity and processing manifest visible.
- [ ] Auth, access roles, private location handling, audit trail, abuse controls tested.
- [ ] Cross-community collaboration exercised by genuinely different users.
- [ ] Backend tests, frontend build + E2E smoke test, migration tests, data recovery runbook pass.
- [ ] Error/loading/offline handling, mobile layouts, keyboard accessibility and EN/ES checked.
- [ ] Version tag, known limitations, licenses and attribution docs complete.
- [ ] Demo live URL and reproducible deploy steps independently validated.

Generated **case investigations** are part of 1.0.
