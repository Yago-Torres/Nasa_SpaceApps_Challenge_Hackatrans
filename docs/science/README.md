# Scientific source policy

`SCIENTIFIC_POLICY.md` governs scientific claims, observable uncertainty, literature verification and review of agricultural case investigations. Literature is used as an evidence source for the **tool**, and case reports are product outputs.

`EVIDENCE_CLAIMS.md` defines the structured claim record, licence/access rules and the human review protocol (ABB-14).

`CONTRADICTIONS_APPLICABILITY.md` defines candidate disagreements between claims (human-confirmed) and per-dimension transferability notes without any applicability score (ABB-15).

`UNCERTAINTY_HUNTER.md` defines the gap inventory, local questions with what they could change (never a value-of-information estimate), the link-count ordering with an explicit "no basis to prioritise" result, and reviewable local answers (ABB-19).

`EVIDENCE_GRAPH.md` defines the case evidence graph, human-authored conclusions, edge rules and the trace back to original evidence (ABB-16).

`HLS_VEGETATION.md` defines the HLS v2.0 NDVI observations at a point: Fmask QA, the 3 × 3 window, the clear rule, missing dates as gaps and why NDVI is not soil health (ABB-12).

`GPM_PRECIPITATION.md` defines the GPM IMERG Final monthly precipitation for the 0.1° cell at a point, the rate-to-total conversion, its error estimate and the month-by-month comparison with NASA POWER without regridding (ABB-09).

`CASE_REPORT.md` defines the versioned, immutable, hash-verified case report and its Markdown/HTML/JSON exports, what they contain, what is never exported and how integrity is checked (ABB-26).
