# Scientific source policy

`SCIENTIFIC_POLICY.md` governs scientific claims, observable uncertainty, literature verification and review of agricultural case investigations. Literature is used as an evidence source for the **tool**, and case reports are product outputs.

`EVIDENCE_CLAIMS.md` defines the structured claim record, licence/access rules and the human review protocol (ABB-14).

`EVIDENCE_GRAPH.md` defines the case evidence graph, human-authored conclusions, edge rules and the trace back to original evidence (ABB-16).
